## 🗺️ 建議練習順序

1. **每天**：軌道 1 刷 1-2 題（維持演算法手感）+ 軌道 5/6/7 練 1 題前端手寫/觀念/渲染
2. **每週**：軌道 3 補一個計概主題（弱點優先）+ 軌道 2 練 2-3 題手寫實作
3. **週末/專案時間**：軌道 4 推進一個後端小專案

> 軌道 1 + 5 + 6 + 7 是你的**得分區**（前端職通常考演算法 + 前端專業）；軌道 2/3 是考試制的**補強區**。

## ✅ 使用方式

每個軌道是一個資料夾，內含 `README.md`（題目目錄）與每題一個子資料夾：

- **可執行程式題**（前端手寫題、外商刷題、程式設計概論…）：
  - `題目.js`：題目敘述 + 函式 stub + 測試 → 你動手填，`node 題目.js` 會 fail
  - `答案.js`：完整解答，`node 答案.js` 印出 `✅ 通過`
  - 練法：先寫 `題目.js` 跑到綠燈，再對照 `答案.js`
- **觀念/專案題**（計概、Node 專案）：`題目.md` + `答案.md`，先自己想再看解析
- **React/Next 可視化題**（軌道 6、7）：`npm install && npm run dev` 打開瀏覽器，每題一個 route，頁面裡「題目」「答案」兩個元件並排，用 React DevTools Profiler / Chrome Performance 面板實際比較渲染行為；`npm run test` 跑 Vitest。只有「不看畫面就沒意義」的題目才放這裡，純 JS/演算法/觀念題一律留在軌道 5。
