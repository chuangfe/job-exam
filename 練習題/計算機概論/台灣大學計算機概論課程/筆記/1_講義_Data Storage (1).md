## Two's Complement 二補數表示法

假設是 3 bit，則表格如下（3 bit 共有 2³ = 8 種 pattern，可表示 -4 ~ 3）：

| 二進位 | 十進位 |
|---|---|
| 011 | 3 |
| 010 | 2 |
| 001 | 1 |
| 000 | 0 |
| 111 | -1 |
| 110 | -2 |
| 101 | -3 |
| 100 | -4 |

如果想從 10 進位轉為 Two's Complement 對應的二進位，有以下兩種方式：

### 方法 1：反轉法

對應正常二進位的數字，**從右側（LSB）開始照抄，照抄到（且包含）第一個出現的 1 為止；再往左剩下的 bit 全部取反（0↔1）**。

例如：十進位 2 轉為二補數表示法的 -2

```
正常二進位：010
從右抄到第一個 1（含）：抄下 0、1 → 剩左邊的 0 取反成 1
結果：110
```

### 方法 2：公式計算法

```
正數：直接寫該數字的二進位，不用轉換
負數 -x：2ⁿ（n 是 bit 數）+ 該負數，再轉二進位
```

例如：想知道十進位的 -4 在表中對應的二進位

```
2³ + (-4) = 8 - 4 = 4
4 轉二進位 = 100
```

對照表格：100 → -4，正確。

## Excess Notation 增碼表示法

假設是 3 bit，則表格如下（3 bit 共有 2³ = 8 種 pattern，可表示 -4 ~ 3）：

| 二進位 | 十進位 |
|---|---|
| 111 | 3 |
| 110 | 2 |
| 101 | 1 |
| 100 | 0 |
| 011 | -1 |
| 010 | -2 |
| 001 | -3 |
| 000 | -4 |

如果想從 10 進位轉為 Excess Notation 對應的二進位，方式如下：

### 公式計算法

```
不分正負數，一律：2ⁿ⁻¹（n 是 bit 數）+ 該數字，再轉二進位
```

例如：

```
十進位 0  → 2³⁻¹ + 0  = 4 + 0  = 4 → 100
十進位 2  → 2³⁻¹ + 2  = 4 + 2  = 6 → 110
十進位 -1 → 2³⁻¹ + (-1) = 4 - 1 = 3 → 011
```

對照表格，三個結果都正確。

## 兩者的關鍵差異

| | 正數要不要加偏移量？ | 負數要加多少？ | bit pattern 排序 |
|---|---|---|---|
| Two's Complement | 不用，直接用 | 加 2ⁿ | 正負交界處會「繞圈跳躍」 |
| Excess Notation | 要，一律都加 | 加 2ⁿ⁻¹ | 跟數值大小完全同步遞增，不繞圈 |

- **比較大小**：兩者都算簡單（Two's Complement 只要多判斷一次符號位即可，Excess Notation 甚至不用特殊處理）。
- **加法**：Two's Complement 可以直接用一般加法器、丟掉溢出的進位就對了；Excess Notation 直接相加會多一個偏移量，事後要再扣掉一次 2ⁿ⁻¹ 才會修正回正確答案。
- Excess Notation 因為順序不繞圈，常用在需要「直接比大小」的場合，例如 IEEE 754 浮點數的指數欄位（單精度用 Excess-127）。
