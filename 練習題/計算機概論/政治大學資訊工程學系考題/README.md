# 政大資訊科學系碩士（在職專班）考古題彙整

> 用途：國立政治大學資訊科學系碩士在職專班 116 學年度招生，筆試科目名稱雖寫「計算機概論」，但經比對歷年試題確認，實際考試內容是「資料結構及演算法」「作業系統」「計算機數學（離散數學＋線性代數）」三科，難度相當於資工系大學部主科，全英文出題，非入門通識考卷。
> 來源：使用者自行下載的 104～115 學年度政大資訊科學系（碩士班暨碩士在職專班）招生考試 PDF。依中華民國著作權法第 9 條第 1 項第 5 款「依法令舉行之各類考試試題及其備用試題」不得為著作權之標的，故逐題忠實轉錄不涉及侵權。
> 流程：每份 PDF 先由一個 subagent 逐題轉錄成 Markdown，再由另一個獨立 subagent 重新對照原始 PDF 校對、修正錯誤（過程詳見下方「校對記錄」）。

## 重要提醒

- **104～107 年**的試題頁首／系所別欄位明確標示「資訊科學系－一般生」，可能是一般全職碩士班的考卷，不一定是在職專班專屬試題；**108～115 年**才明確標示「在職專班」或「碩士班暨碩士在職專班」共用。練習時僅供參考歷年考點分布，不代表 104-107 年的難度/組別與你實際要考的完全相同。
- 112 學年度**沒有「計算機數學」科目**，只考「作業系統」＋「資料結構及演算法」，代表科目組合並非每年固定三科。
- 108 學年度額外考了一科「機率」，是 12 年中唯一出現機率科目的年份。
- 圖形類題目（樹、圖、DFA 狀態圖等）用文字描述節點與邊，已盡力透過高解析度比對還原，但仍建議對照原始 PDF 圖像複核一次再動手解題。

## 校對記錄

每份檔案都經過兩輪獨立 subagent 校對：第一輪逐題比對原始 PDF 並修正，第二輪再用全新 subagent（含高解析度裁圖）覆核第一輪的修正是否正確、有無漏抓。

**第一輪**確認過的錯誤：104 年兩張手繪圖（生成樹節點/邊權重）誤植、107 年漏轉錄 3 題離散數學證明題、108 年一題選項轉錄錯誤、109 年 DFA 狀態圖多處方向標籤錯誤、110 年標題文字誤植、115 年 Prim's MST 圖權重誤植（影響 10% 配分的大題）。105、106、111、112、113、114 年第一輪即**完全正確、未修改**。

**第二輪**（僅針對第一輪有修正的 7 份年度再複查）：105、109、115 年確認第一輪修正完全正確、無新問題；104、107、110 年各再抓到一處新的小瑕疵（圖形位置描述文字、圖形說明自相矛盾、多餘的「組別：—」欄位）並修正；**108 年再抓到一個實質錯誤**——vertex cover 樹狀圖的邊第一輪記錯了（巧合通過題目給的驗證條件但圖不對），高解析度重新比對後確認正確邊為 A-B、B-C、A-E、D-E、E-F、F-G，已修正。

這也印證了圖形類題目（樹、圖、DFA）是轉錄最容易出錯、也最需要多輪覆核的部分；純文字題幹、選項、矩陣數值經兩輪比對後已高度可信。
