## 🧾 勞保投保明細

**網址：<https://edesk.bli.gov.tw/>**（勞動部勞工保險局「e 化服務系統」）

> ⚠️ 2026-08-11 實測：「勞保局行動服務」App **已下架**，只能走網頁版。手機瀏覽器可開，步驟相同。

| 步驟 | 操作 |
|------|------|
| 1 | 進入 e 化服務系統 |
| 2 | 選擇登入身分 → **個人**（不是投保單位） |
| 3 | 選擇登入方式並驗證 |
| 4 | 個資宣告頁面 → 同意、確認 |
| 5 | 點選**查詢** → 勞工保險、就業保險及勞工職業災害保險 |
| 6 | 條件查詢 → **選「全部揭露」**（要讓完整年資與所有投保單位呈現） |
| 7 | 滾到網頁最下方 → 選 **PDF 列印** |
| 8 | 遮蔽選項**都不要打勾**（明細皆需顯示） |
| 9 | 下載後列印，**本人於空白處簽名**（紙本備用；上傳用原始 PDF 即可） |

### 登入方式（挑最快的）

| 方式 | 需要什麼 | 難度 |
|------|---------|------|
| **行動電話認證** | 本人**月租型**門號的手機／平板，免插卡、免讀卡機。⚠️ 驗證時需**關閉 Wi-Fi、走行動網路** | ⭐ 最快 |
| 行動自然人憑證（TW FidO） | 已註冊 TW FidO | ⭐ |
| 健保卡 + 註冊密碼 | 讀卡機 + 已在健保署註冊密碼 | ⭐⭐ |
| 自然人憑證 | 讀卡機 + 憑證 IC 卡 + PIN | ⭐⭐⭐ |

**備案**：線上驗證卡住可**臨櫃**至勞保局各地辦事處申請勞保異動明細（帶身分證、印章）。

### 拿到後核對

- [ ] 投保單位名稱與履歷填的公司名稱**一致**（登記名 vs 品牌名常不同）
- [ ] 加退保日期能算出所需年資
- [ ] 空窗期能用一句話說明
- [ ] 若有職業工會投保／派遣／兼職段落 → 可能無法證明「全職」，需補在職或離職證明

> 💡 **勞退專戶另外查**：勞保與勞退是兩套。若某段任職期間勞保查無紀錄，可查「勞工退休金個人專戶」看該僱主是否曾提繳 —— 有的話就是該段任職的書面證據。

### 現場流程與注意事項

**流程**：現場有**自助機器可自動繳費列印**（學校的「成績列印暨自動化繳費系統」），不必等櫃台承辦。櫃台辦理則為：填表 → 繳驗證件 → 繳費 → 取件。

**要帶**：身分證正本、印章、現金零錢、學號（忘記可用身分證查）。
**代辦**：需委託書（教務處網站「表單下載」有 odt／pdf）+ 委託人身分證影本 + 受託人身分證正本。

**櫃台講法**（避免拿錯文件）：
> 「我是畢業校友，要申請**中文歷年成績單**，需要**含全部學期**的完整版本，用於應徵工作，麻煩開正式文件。」

### 機器列印要檢查的 5 件事

1. **選「歷年成績單」** —— 不是單一學期，也不是在學證明書
2. **檢查有無學校印信**（關防／鋼印／騎縫章）；無印信就拿櫃台加蓋，多頁務必騎縫
3. **確認科系名稱完整顯示** —— 多數招募的資格審查看這一欄
4. **多印 2–3 份** —— 機器便宜，省得下次再跑
5. 當天**掃成 PDF**，確認清晰且符合上傳系統的大小限制

> ⚠️ 學校自 114 學年起試行**無紙本成績單**，線上系統可列印的是「中文在學證明書」等，未必等同正式的「全份學業成績單」→ **以現場申請正本為準**。
> 校友帳號登入不了不影響辦理 —— **現場辦理不需要系統帳號**。
